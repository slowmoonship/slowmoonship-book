# SUI 05 小结｜资金不是对象数量

Coin 是带身份的资金容器，Balance 是类型化的数值，T 识别资产。Split 与 Merge 可以增加或减少 Coin 数量，却不因此改变资产总价值。对象创建或删除也不能直接当作增发或销毁。

当前 Coin 与 Address Balance 共存。地址总余额需要在相同主体、币种和时点合并存活 Coin 与累加器值。只有 Coin 对象数据，可能遗漏地址余额；只有当前余额，也不能还原过去每一次业务动作。

资产身份采用完整 Coin Type，Symbol 只辅助显示。数量先保存原始整数，再依据核验精度转换；价格与美元估值需要额外时间证据。历史对象版本不能累加成钱包当前资金。

Gas Budget 表达预算，Effects 表达实际费用。Sender、费用承担者与收款人可以不同，Swap 投入与 SUI 费用也要分开。存储返还可能使净费用为负，分析应按公式与数据来源解释，不能先把负数删掉。

从现在开始，看到资金变化时要追问：资产 Type 是什么，数值属于谁，位于哪个时间位置，是否同时覆盖 Coin、地址余额和费用。下一模块会用 Effects 与 Events 区分实际结果和业务叙述。
