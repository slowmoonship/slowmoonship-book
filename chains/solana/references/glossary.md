# 技术术语索引

| 术语 | 本篇用法 | 阅读位置 |
| --- | --- | --- |
| Slot 时隙 | 带编号的出块机会 | 01.01 |
| Block 区块 | 组织交易的已产出账本对象 | 01.01 |
| Transaction 交易 | 带签名的执行请求；结果另由执行产生 | 02.01 |
| Signature 签名 | 对消息的密码学授权；首签名用作交易标识 | 02.02 |
| Signer 签名者 | 对消息签名的账户；不同于被调用的所有地址 | 02.02 |
| Fee payer 付费者 | 付交易费用的首个签名账户 | 02.02 |
| Instruction 指令 | 要求程序执行的一项动作 | 03.01 |
| Program 程序 | 实现执行逻辑的链上程序 | 03.01 |
| CPI 跨程序调用 | 程序执行中调用另一程序指令 | 03.02 |
| Inner instruction 内层指令 | 运行时记录的内部调用 | 03.02 |
| Account 账户 | 按地址定位的状态单元 | 04.01 |
| Owner 程序所有者 | 基础账户中负责数据的程序 | 04.01 |
| Authority 授权者 | 程序定义的业务操作权限角色 | 04.02 |
| PDA 程序派生地址 | 按 seeds 与 program ID 确定、无私钥的地址 | 04.02 |
| Mint 代币发行账户 | 资产身份及供给、小数位、发行权限 | 05.02 |
| Token Account 代币账户 | 某 mint 的余额及授权状态 | 05.02 |
| ATA 关联代币账户 | 确定地址规则下的默认 token account | 05.02 |
| ALT 地址查找表 | v0 消息通过索引引用地址的机制 | 02.04 |
| CU 计算单位 | 执行消耗的计量单位 | 03.03 |
| RPC 远程过程调用 | 读取状态、历史及执行信息的接口 | 06.01 |
| Grain 粒度 | 一行代表的对象或事件 | 06.02 |
| IDL 接口定义 | 按程序接口解释指令与参数的定义 | 03.04 |
