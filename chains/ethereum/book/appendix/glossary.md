# 术语表

| 英文 | 中文 | 本篇含义 |
|---|---|---|
| Transaction | 交易 | 获得授权并提交到执行历史的顶层请求。 |
| Trace | 执行轨迹 | 客户端或索引器按执行生成的调用或更细记录，不是新增用户交易。 |
| Log / Event | 日志／事件 | 事件是程序声明，日志是它被保留的编码记录。 |
| State | 状态 | 指定位置保存的账户与持久存储内容。 |
| EOA | 外部账户 | 传统由密钥授权顶层交易；现代可有委托标记。 |
| Contract Account | 合约账户 | 部署代码响应调用的账户，按代码规则执行。 |
| Nonce | 请求／创建计数 | 账户计数器，不能当作成功业务数。 |
| Calldata | 调用输入 | 当前调用接收的输入字节。 |
| ABI | 二进制接口 | 规定函数、事件与类型编码的接口描述。 |
| Selector | 函数选择器 | 常规 ABI 调用的四字节签名摘要前缀。 |
| Topic | 索引主题 | 日志索引位置；非匿名事件首项通常为签名摘要。 |
| Storage | 持久存储 | 账户状态的一部分。 |
| Memory / Stack | 内存／栈 | 调用帧执行过程使用的临时空间。 |
| Delegatecall | 委托调用 | 借用代码，保留调用方上下文。 |
| Revert | 回滚 | 撤销相应业务执行范围；费用与协议前置处理另判。 |
| Allowance | 授权额度 | 代币使用权限，不是已经转移的资产。 |
| Decimals | 显示精度 | 最小单位到人类显示单位的换算位数。 |
| Wei / Gwei | 原生单位 | 一 ETH 为十的十八次方 Wei，十的九次方 Gwei。 |
| Gas Used / Limit | 使用量／上限 | 资源计费数量与允许上限，不是单价。 |
| Base / Priority Fee | 基础／优先费 | 适用规则下的销毁部分与实际优先支付。 |
| Blob | 数据发布材料 | 通过摘要引用，与普通 Calldata 和持久 Storage 分开。 |
| Slot / Epoch | 时间机会／周期 | 当前基础 PoS 为十二秒 Slot、三十二 Slot Epoch。 |
| Withdrawal | 协议提款 | 共识驱动的载荷操作，不是普通用户交易。 |
| Raw / Decoded / Curated | 原始／解码／加工 | 三类组织和解释层次，可能重叠表达同一活动。 |
| Grain | 数据粒度 | 一行记录代表的实体或观察单位。 |
| Candidate Key | 候选键 | 预期定位身份的字段组合，实际唯一性需验证。 |
| State Diff | 状态差异 | 前后状态变化资料，不由事件数量自动推导。 |
| UserOperation | 用户操作对象 | ERC-4337 应用授权与操作对象，由顶层交易承载。 |
